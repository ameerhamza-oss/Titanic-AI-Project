# 🚢 Titanic Survival Prediction AI Project

## 📌 Project Overview
This project uses Machine Learning to predict whether a passenger survived the Titanic disaster.

The complete workflow includes data analysis, visualization, model training, evaluation, and saving the trained AI model.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Jupyter Notebook

## 📊 Project Workflow
✔ Data Loading  
✔ Data Cleaning  
✔ Exploratory Data Analysis (EDA)  
✔ Data Visualization  
✔ Feature Engineering  
✔ Machine Learning Model Training  
✔ Model Evaluation  
✔ Model Saving  

## 🤖 Machine Learning Model
A classification model was trained to predict passenger survival.

## 📈 Model Performance

Accuracy:1.0

## 📂 Project Files

- `Titanic_Analysis.ipynb` → Complete analysis and model training
- `titanic.csv` → Dataset
- `titanic_model.pkl` → Saved trained model
- `requirements.txt` → Required Python libraries
