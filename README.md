# Titanic Survival Prediction AI Project

## Project Overview
This project uses Machine Learning to predict whether a passenger survived the Titanic disaster or not.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Machine Learning Model
The model is trained using classification algorithms to predict passenger survival.

## Project Steps
- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
- Model Training
- Model Evaluation
- Model Saving

## Model Performance
Accuracy:
1.0

## Files
- Titanic_Analysis.ipynb → Complete analysis and model training
- titanic.csv → Dataset
- titanic_model.pkl → Trained Machine Learning model
- requirements.txt → Required libraries
